## How to capture them

1. Start all three services (see the root `README.md`).
2. Sign in as `admin@plantdisease.com` / `Admin@123` for the admin shots.
3. Capture at 1440 × 900 to keep the sidebar layout intact.
4. Name the files exactly as listed above and drop them in this folder.

> Until the real screenshots are added, the README section simply says so —
> a placeholder image is worse than an honest note.

These files are deliberately **not** git-ignored, so real screenshots can be
committed here.
